はじめに
RIFとは何か
アドラー心理学の「人の悩みはすべて対人関係にある」を出発点に、人に求められる素質をRelational（関係性）という軸で再定義したモデルです。

IQは思考力を測り、EQは感情知性を測ります。しかしRIFが問うのは、その先——関係性の中で、あなたはどれほどの価値を生み出せるか。最終的な成果はRQ（Relational Intelligence）で決まります。
Domain A
Thinking（認知・論理）
CI / TI / FI — 考える力、テクノロジー、金融知性
Domain B
Relational（情緒・対人）
EI / CuI / LI — 感情・文化理解・信頼形成
Domain C
Inner（内省・価値観）
SI / MI / HI / AeI — 意味・倫理・幸福・審美
Domain D
Action（行動・身体）
AI / XI / BI — 逆境耐性・実行力・身体知性
RI（Relational Intelligence）は、B・Cドメインの4つのサブスコア（EI・LI・CuI・SI）から自動算出されます。これがあなたの「関係性知性」の核心値です。
